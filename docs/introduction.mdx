# Welcome to the DeepSecure SDK

This documentation provides everything you need to integrate the DeepSecure SDK into your AI Agent applications.

The DeepSecure SDK provides a simple, powerful interface for:
- Managing AI Agent identities
- Securely retrieving secrets and credentials from a centralized vault
- Enforcing fine-grained access control policies

## Getting Started

To get started, head over to the **API Reference** section to explore the available methods.
